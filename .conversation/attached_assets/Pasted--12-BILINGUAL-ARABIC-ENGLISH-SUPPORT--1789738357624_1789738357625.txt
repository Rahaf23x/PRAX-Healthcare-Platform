==================================================
12. BILINGUAL ARABIC / ENGLISH SUPPORT
==================================================

The entire PRAX platform must support BOTH Arabic and English.

Add a clearly visible language switcher in the header:
- العربية
- English

Default language: English

When the user selects Arabic:
- Translate the entire interface into Arabic
- Automatically switch the layout direction to RTL
- Align text, menus, cards, tables, icons, and navigation appropriately for RTL
- Use Arabic-friendly fonts
- Ensure Arabic text is readable and professionally formatted

When the user selects English:
- Translate the entire interface into English
- Automatically switch the layout direction to LTR
- Restore English alignment and layout

IMPORTANT:
The language switch must work throughout the entire application, not only on the landing page.

All of the following must be translated:
- Navigation
- Dashboard
- Buttons
- Patient information
- Medical history
- Vital signs
- AI clinical support
- Alerts
- Physician consultation
- Hospital interface
- Hospital readiness
- Notifications
- Settings
- Login / role selection
- Error and success messages
- Status labels
- Tables
- Forms
- Modals
- Tooltips
- Empty states
- Confirmation messages

Create a centralized translation system using JSON or TypeScript translation objects, for example:

English:
Dashboard
Active Patient
Medical History
Vital Signs
AI Clinical Support
Physician Consultation
Hospital Readiness
Alerts
Patient Verified
Critical Alert
Emergency Readiness

Arabic:
لوحة التحكم
المريض الحالي
التاريخ الطبي
العلامات الحيوية
الدعم السريري بالذكاء الاصطناعي
استشارة الطبيب
جاهزية المستشفى
التنبيهات
تم التحقق من هوية المريض
تنبيه حرج
جاهزية الطوارئ

Do NOT hardcode interface text separately in different components.

Use a single translation system so the language can be changed instantly without reloading the page.

The selected language should persist while navigating between pages.

BILINGUAL DEMO EXPERIENCE
==================================================

The demo should work exactly the same in both languages.

Example:

English:
"Patient Verified"
"Critical Allergy Detected"
"Penicillin allergy found in the patient's medical record."

Arabic:
"تم التحقق من هوية المريض"
"تم اكتشاف حساسية حرجة"
"تم العثور على حساسية من البنسلين في السجل الطبي للمريض."

The AI clinical support messages must also be translated according to the selected language.

The disclaimer must be bilingual:

English:
"PRAX is a prototype for demonstration purposes. Patient data shown is fictional."

Arabic:
"PRAX نموذج أولي لأغراض العرض والتجربة. جميع بيانات المرضى المعروضة وهمية."

Make sure Arabic and English layouts remain visually balanced and professional.
